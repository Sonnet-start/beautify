# Project Brief

## Цель проекта
Создание премиального веб-приложения "Мой личный косметолог" для получения персонализированных рекомендаций по уходу за кожей лица с использованием ИИ-технологий (Google Gemini).

## Целевая аудитория
Люди всех возрастов и полов, желающие улучшить состояние кожи, ищущие структурированный подход к уходу и отслеживающие изменения кожи во времени.

## Технологический стек
- **Frontend/Backend**: Next.js 16 (App Router)
- **База данных**: Supabase (PostgreSQL)
- **AI**: Google Generative AI (Gemini 3 Flash)
- **Аутентификация**: Supabase Auth
- **Хранение файлов**: Supabase Storage
- **Управление состоянием**: Zustand + TanStack Query
- **UI**: Tailwind CSS 4, Radix UI, Framer Motion
- **Линтинг**: Biome

## Страницы приложения
- `/` - Главная
- `/dashboard` - Дашборд пользователя
- `/profile` - Профиль и настройки
- `/consultation` - ИИ-консультации
- `/analysis` - Анализ фото кожи
- `/calendar` - Календарь ухода
- `/design-demo` - Демо дизайн-системы
- `/auth/login`, `/auth/signup`, `/auth/verify` - Аутентификация
