# Active Context

## Текущий фокус
Ведется работа над UI-редизайном страниц консультаций и анализа, улучшение визуального отображения рекомендаций ИИ.

## Активные решения
- Использование Gemini AI для генерации рекомендаций
- Хранение истории консультаций в Supabase
- Защищенный вызов AI через Edge Functions

## Приоритеты
1. Завершение отслеживания прогресса (фото До/После)
2. Полировка UI и анимаций
3. Исправление мелких багов
