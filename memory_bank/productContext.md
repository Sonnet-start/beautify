# Product Context

## Зачем нужен проект
Приложение "Мой личный косметолог" демократизирует доступ к профессиональным косметологическим знаниям, используя искусственный интеллект для персонализации рекомендаций по уходу за кожей.

## Проблемы пользователей
1. Отсутствие доступа к профессиональным косметологическим консультациям
2. Сложность самостоятельного подбора средств для ухода
3. Невозможность отслеживать прогресс состояния кожи
4. Отсутствие персонализированных рекомендаций

## Решения
1. ИИ-консультации через Google Gemini с учетом профиля пользователя
2. Структурированные программы ухода (утро/вечер)
3. Анализ фото кожи для визуальной оценки
4. Календарь процедур и отслеживание прогресса
